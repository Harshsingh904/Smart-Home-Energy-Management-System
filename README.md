# Smart Home Energy Management System

A machine learning project focused on analyzing household electricity consumption data to understand energy usage patterns and support smarter energy management.

## Project Overview

The Smart Home Energy Management System uses historical household electricity consumption data to explore energy usage patterns through data preprocessing, visualization, and machine learning.

The project is developed using Python in Google Colab.

## Objectives

* Analyze household electricity consumption.
* Preprocess and prepare energy data for machine learning.
* Visualize electricity usage patterns.
* Train and evaluate a machine learning model.
* Explore how data-driven insights can support energy management.

## Dataset

**Dataset:** Individual Household Electric Power Consumption

**Source:** UCI Machine Learning Repository

[Download the dataset](https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption)

**Dataset file:** `household_power_consumption.txt`

The dataset contains measurements of household electric power consumption collected over time.

Download the dataset separately and place it in the location expected by the notebook before running the project.
